# 챔버 과온 보호 동작 시나리오 및 원인별 분석

| 문서번호 | SCN-001 |
|---------|---------|
| Rev | H |
| 작성일 | 2026-04-28 |
| 작성자 | 임재형 |
| 분류 | Firmware / Verification |
| 활용 목적 | 과온 보호 동작 검증 및 이상 원인 분석 |

---

## 1. 문서 목적

본 문서는 히터 기반 온도 제어 펌웨어에서 과온 알람이 발생했을 때, **알람 안정화 → 원인 후보 분류 → 검증 우선순위 결정 → 원인 확증 → 복구 및 재가동 검증**까지 이어지는 분석 체계를 정리한 문서이다.

특히 단순히 “알람이 발생했다”에서 끝내지 않고, 알람 발생 전후의 운전이력 로그와 벤치 계측값을 기반으로 원인을 좁혀 재발 방지까지 연결하는 것을 목표로 한다.

---

## 2. 적용 범위

본 문서는 아래 알람 발생 시 적용한다.

| 알람 ID | 알람명 | 발생 조건 | 의미 |
|--------|--------|----------|------|
| ALM-01 | TEMP_WARNING | 설정온도보다 일정 수준 이상 상승 | 과온 주의 단계 |
| ALM-02 | TEMP_ALARM | 과온 상태가 일정 시간 이상 지속 | 운전 정지 및 복구 대기 단계 |

본 문서에서 다루는 주요 분석 대상은 다음과 같다.

- 온도센서 표시값 이상 여부
- 냉각팬 및 풍량 이상 여부
- 주변 환경 및 설치 조건 변화
- 히터 출력 제어값 과다 여부
- 히터 출력 차단 회로 이상 여부
- 알람 후 복구 시퀀스 및 재가동 검증

---

## 3. 과온 알람 발생 시 자동 안전 동작

과온 알람이 발생하면 펌웨어는 사용자가 개입하기 전에 먼저 히터 출력을 차단하고 냉각팬을 작동시킨다.

### 3.1 WARNING 단계

| 항목 | 동작 |
|------|------|
| 운전 상태 | HEATING → WARNING |
| 히터 | 히터 출력률 0%로 감소 |
| 냉각팬 | ON |
| 부저 | 간헐음 |
| 제어기 이벤트 | `EVENT:WARN,ALM-01` |
| 자동 해제 조건 | 온도가 설정온도 근처로 복귀하면 WARNING 해제 |

**판단 포인트**

WARNING 단계에서 팬이 켜지고 온도가 정상적으로 하강하면 일시적인 과온으로 볼 수 있다. 반대로 팬이 켜졌는데도 온도가 계속 오르거나, 팬 자체가 동작하지 않으면 즉시 원인 분석을 시작한다.

### 3.2 ALARM 단계

| 항목 | 동작 |
|------|------|
| 운전 상태 | WARNING → ALARM |
| 히터 | 히터 출력률 0%로 즉시 차단 |
| 냉각팬 | ON |
| 부저 | 연속음 |
| 제어기 이벤트 | `EVENT:ALARM,ALM-02` |
| 복구 조건 | 온도가 설정온도보다 충분히 낮아진 뒤 RESET 가능 |

**안전 설계 원칙**

ALARM 상태에서는 온도가 충분히 내려가기 전까지 RESET 명령을 거부한다. 따라서 원인 조치 전에는 무리하게 재가동하지 않고, 온도 하강 여부와 히터 차단 여부를 먼저 확인한다.

## 4. EC 모니터 화면 판독 순서

ALARM 발생 직후에는 아래 순서로 모니터 화면을 판독한다.

```text
[State]   운전 상태: ALARM

[Sensor]  현재 온도: 32.5°C
          설정온도: 30.0°C
          히터 출력률: 0.0%

[Run]     운전 시간: 77.3s
          목표 도달 시간: 45.2s
          안정화 시간: ---

[KPI]     최고 온도: 32.8°C
          목표 온도 초과량: 2.8°C

[Alarm]   ALM-02 TEMP_ALARM
          복구 조건: 현재 온도 ≤ 28.0°C
          현재 상태: 복구 조건 미충족
```

| 확인 항목 | 정상 판단 | 이상 판단 |
|----------|----------|----------|
| 히터 출력률 | ALARM 후 0% | 0%가 아니면 제어 차단 이상 |
| 현재 온도 추이 | 팬 동작 후 서서히 하강 | 출력률 0%인데도 계속 상승 |
| 목표 온도 초과량 | 1°C 이내 | 2~3°C 이상이면 제어 또는 냉각 문제 의심 |
| 안정화 시간 | 일정 시간 후 표시 | 계속 `---`이면 안정화 실패 |
| 팬 동작 | WARNING/ALARM에서 ON | 팬 미동작 또는 풍량 부족 |

## 5. 원인 분류 및 점검 우선순위

### 5.1 우선순위 산정 기준

본 문서의 원인 순서는 실제 양산 장비의 통계가 아니라, 프로젝트 환경에서의 **예상 발생 가능성, 검증 효율, 안전 영향도**를 함께 고려한 순서이다.

| 기준 | 의미 |
|------|------|
| 예상 발생 가능성 | 해당 원인이 프로젝트 환경에서 발생할 가능성 |
| 검증 효율 | 짧은 시간, 적은 도구, 비파괴 방식으로 확인 가능한 정도 |
| 안전 영향도 | 즉시 차단 또는 전원 OFF가 필요한 위험도 |

### 5.2 최종 원인 코드

| 원인 코드 | 개선된 원인명 | 기존 원인명 | 우선 확인 방법 | 확증 방법 |
|----------|--------------|------------|--------------|----------|
| A | 온도센서 표시값 이상 | 센서 오보 | 외부 온도계와 EC 표시값 비교 | IDLE 상태 로그와 외부 온도 비교 |
| B | 냉각팬 또는 풍량 이상 | 팬·릴레이 불량 | 팬 회전음, 진동, 풍량 확인 | 팬 구동 신호, 릴레이, 팬 전원 확인 |
| C | 주변 환경 열부하 증가 | 환경 온도 상승 | 실내 온도, 인접 열원, 환기 상태 확인 | 과거 로그 대비 기저 온도 상승 확인 |
| D | 히터 출력 제어값 과다 | PID 게인 과다 | 목표 온도 초과량 및 히터 출력률 추이 확인 | 설정온도 근처에서 출력률 급변 여부 확인 |
| E | 히터 출력 차단 불량 | MOSFET 고장 | ALARM 후 출력률 0%인데 온도 상승 여부 확인 | 히터 구동 신호 및 전력 스위칭 소자 전압 확인 |

### 5.3 점검 우선순위

| 순위 | 원인 | 예상 소요 시간 | 필요 도구 | 우선순위 이유 |
|-----|------|--------------|----------|--------------|
| 1 | A. 온도센서 표시값 이상 | 2분 | 외부 온도계 | 실제 과온인지 오경보인지 가장 빠르게 구분 가능 |
| 2 | B. 냉각팬 또는 풍량 이상 | 3~5분 | 육안, 청각, 멀티미터 | 과온 대응 부품이므로 빈도와 영향도가 모두 높음 |
| 3 | C. 주변 환경 열부하 증가 | 5분 | 온도계, 운전이력 로그 | 비파괴적으로 확인 가능하며 설치 조건 변화와 연관 |
| 4 | D. 히터 출력 제어값 과다 | 10분 | 운전이력 로그, 필요 시 로직분석기 | 소프트웨어/제어 원인으로 로그 분석이 선행되어야 함 |
| 5 | E. 히터 출력 차단 불량 | 15분 이상 | 멀티미터, 로직분석기 | 발생 빈도는 낮지만 안전 영향이 커서 조건 만족 시 즉시 점검 |

> 안전 예외: ALARM 후 히터 출력률이 0%인데도 온도가 계속 상승하면, 순서와 관계없이 즉시 24V 전원을 차단하고 원인 E를 먼저 점검한다.

## 6. 분석 흐름

```text
과온 알람 발생
   │
   ▼
[Safety Gate] ALARM 후 히터 출력률 0% 확인
   │
   ├─ 출력률 0%인데 온도 계속 상승
   │      → 즉시 전원 차단 후 원인 E 점검
   │
   └─ 온도 하강 또는 상승 멈춤
          │
          ▼
[Step 1] 외부 온도계로 센서 표시값 확인
          │
          ├─ EC 표시값과 외부 온도 차이 ≥ 2°C
          │      → 원인 A: 온도센서 표시값 이상
          │
          └─ 센서 표시값 정상
                 │
                 ▼
[Step 2] 냉각팬 회전, 진동, 풍량 확인
                 │
                 ├─ 팬 미동작 또는 풍량 부족
                 │      → 원인 B: 냉각팬 또는 풍량 이상
                 │
                 └─ 팬 정상
                        │
                        ▼
[Step 3] 실내 온도, 주변 열원, 환기 상태 확인
                        │
                        ├─ 평소보다 실내 온도 높음 / 주변 열원 존재
                        │      → 원인 C: 주변 환경 열부하 증가
                        │
                        └─ 환경 정상
                               │
                               ▼
[Step 4] 운전이력 로그에서 히터 출력률과 온도 초과량 확인
                               │
                               ├─ 설정온도 근처에서 출력률 과다 또는 급변
                               │      → 원인 D: 히터 출력 제어값 과다
                               │
                               └─ 출력률 정상인데 과온 지속
                                      → 원인 E 재검토
```

## 7. 운전이력 로그 분석 기준

운전이력 로그는 알람 발생 이전의 온도 변화와 히터 출력 변화를 재구성할 수 있는 핵심 자료이다. 모니터 화면 확인과 함께 가장 먼저 열어본다.

### 7.1 주요 로그 항목

| 로그 항목 | 개선 표현 | 확인 목적 |
|----------|----------|----------|
| temperature_c | 현재 온도 | 실제 온도 상승/하강 추이 확인 |
| setpoint_c | 설정온도 | 목표 온도 기준 확인 |
| duty_pct | 히터 출력률 | 히터가 얼마나 강하게 구동되었는지 확인 |
| fw_state | 운전 상태 | IDLE, HEATING, WARNING, ALARM 구간 구분 |
| peak_temp_c | 최고 온도 | 알람 중 최고 온도 확인 |
| overshoot_c | 목표 온도 초과량 | 제어 안정성 판단 |
| reach_s | 목표 도달 시간 | 과열 또는 출력 부족 판단 |
| settle_s | 안정화 시간 | 설정온도 근처 안정화 여부 판단 |

### 7.2 원인별 로그 패턴

| 원인 | 로그에서 보이는 대표 패턴 |
|------|--------------------------|
| A. 온도센서 표시값 이상 | IDLE 상태에서 히터 출력률 0%인데 표시 온도가 실내 온도보다 비정상적으로 높음 |
| B. 냉각팬 또는 풍량 이상 | WARNING/ALARM 이후 팬 ON 조건인데도 온도 하강이 없거나 매우 느림 |
| C. 주변 환경 열부하 증가 | IDLE 또는 HEATING 초반 기저 온도가 과거 정상 로그보다 높음 |
| D. 히터 출력 제어값 과다 | 설정온도 근처에서도 히터 출력률이 높게 유지되거나 급격히 반복 변동 |
| E. 히터 출력 차단 불량 | ALARM 이후 히터 출력률 0%인데도 온도가 계속 상승 |

### 7.3 로그 분석 절차

```text
1. 알람 발생 시각을 확인한다.
2. WARNING 첫 진입 시점을 찾는다.
3. WARNING 발생 30~60초 전부터 온도와 히터 출력률을 확인한다.
4. ALARM 이후 히터 출력률이 0%로 떨어졌는지 확인한다.
5. 히터 출력률 0% 이후 온도가 하강하는지, 정체되는지, 상승하는지 확인한다.
6. 목표 온도 초과량과 안정화 시간을 확인한다.
7. 로그 패턴을 원인 A~E와 대조한다.
```

## 8. 원인별 상세 분석 및 조치

### 8.1 원인 A — 온도센서 표시값 이상

#### 발생 메커니즘

실제 온도는 정상 범위이나 온도센서가 높은 값을 표시하여 과온 알람이 발생하는 경우이다. 센서가 히터 열풍에 직접 노출되었거나, 설치 위치가 부적절하거나, 배선 접촉 불량 또는 센서 드리프트가 있을 때 발생할 수 있다.

#### 점검 절차

| 단계 | 확인 항목 | 도구 | 방법 | 판정 |
|-----|----------|------|------|------|
| 1 | EC 표시 온도와 외부 온도 비교 | 외부 온도계 | 센서 설치 위치 근처에서 외부 온도를 측정 | 차이 ≥ 2°C이면 이상 |
| 2 | IDLE 상태 표시 온도 확인 | 운전이력 로그 | 히터 출력률 0% 구간의 온도를 확인 | 실내 온도보다 2°C 이상 높으면 이상 |
| 3 | 센서 위치 확인 | 육안 | 히터 표면 또는 열풍 경로와의 거리 확인 | 열풍 직접 노출 시 이상 |
| 4 | 센서 배선 확인 | 멀티미터 | 전원, GND, DATA 결선 및 풀업 저항 확인 | 접촉 불량 또는 풀업 이상 시 이상 |

#### 조치

```text
1. 운전 정지
2. 외부 온도계와 센서 표시값 재확인
3. 센서를 히터 열풍 경로에서 이격
4. 배선 및 풀업 저항 확인
5. 센서 교체
6. IDLE 상태에서 실내 온도와 표시값 일치 여부 확인
7. 재가동 후 알람 재발 여부 확인
```

---

### 8.2 원인 B — 냉각팬 또는 풍량 이상

#### 발생 메커니즘

WARNING 또는 ALARM 단계에서는 냉각팬이 작동하여 온도를 낮춰야 한다. 팬이 동작하지 않거나, 회전하더라도 풍량이 부족하면 온도가 하강하지 않아 ALARM으로 이어진다.

#### 점검 절차

| 단계 | 확인 항목 | 도구 | 방법 | 판정 |
|-----|----------|------|------|------|
| 1 | 팬 회전음, 진동, 풍량 | 육안, 청각, 촉각 | WARNING 직후 팬 회전 여부 확인 | 회전음/풍량 없으면 이상 |
| 2 | 팬 구동 신호 | 멀티미터 | WARNING 상태에서 팬 구동 신호 전압 확인 | 정상 구동 전압이 없으면 제어/배선 이상 |
| 3 | 릴레이 동작 | 청각, 멀티미터 | 릴레이 동작음 및 출력 전압 확인 | 릴레이 미동작이면 이상 |
| 4 | 팬 전원 | 멀티미터 | 팬 입력 전압 확인 | 정격 전압 미인가 시 전원 계통 이상 |
| 5 | 온도 하강률 | 운전이력 로그 | 팬 ON 이후 온도 하강 여부 확인 | 온도 하강 없으면 냉각 성능 이상 |

#### 조치

```text
1. 팬 커넥터 및 전원 배선 확인
2. 팬 구동 신호 확인
3. 릴레이 모듈 또는 팬 전원 모듈 점검
4. 팬 자체 불량 시 교체
5. 팬 교체 후 WARNING/ALARM 조건에서 온도 하강 확인
```

---

### 8.3 원인 C — 주변 환경 열부하 증가

#### 발생 메커니즘

장비 주변의 실내 온도가 높아지거나, 인접 열원이 추가되거나, 환기가 막히면 기본 온도 자체가 상승한다. 이 경우 정상적인 히터 출력에서도 설정온도를 초과하기 쉬워진다.

#### 점검 절차

| 단계 | 확인 항목 | 도구 | 방법 | 판정 |
|-----|----------|------|------|------|
| 1 | 실내 온도 | 외부 온도계 | 현재 실내 온도를 측정하고 평소와 비교 | 평소보다 2°C 이상 높으면 이상 |
| 2 | 인접 열원 | 육안 | 주변 전원장치, 히터, 고온 장비 위치 확인 | 근접 열원 있으면 이상 |
| 3 | 환기 상태 | 육안 | 흡기/배기 경로 막힘 확인 | 막힘 또는 밀폐 시 이상 |
| 4 | 기저 온도 | 운전이력 로그 | IDLE 또는 HEATING 초반 온도를 과거 정상 로그와 비교 | 기저 온도 상승 시 이상 |

#### 조치

```text
1. 주변 열원 제거 또는 이격
2. 흡기/배기 경로 확보
3. 실내 온도 안정화
4. 필요 시 설정온도와 운전 조건 재검토
5. 재가동 후 기저 온도와 알람 재발 여부 확인
```

---

### 8.4 원인 D — 히터 출력 제어값 과다

#### 발생 메커니즘

온도 제어 파라미터가 공격적으로 설정되면 설정온도에 도달한 뒤에도 히터 출력이 과하게 유지되어 목표 온도를 초과한다. 이 경우 온도가 설정온도 근처에서 안정화되지 못하고 오버슈트가 커진다.

#### 점검 절차

| 단계 | 확인 항목 | 도구 | 방법 | 판정 |
|-----|----------|------|------|------|
| 1 | 목표 온도 초과량 | EC 모니터 화면 | 최고 온도와 목표 온도 초과량 확인 | 2°C 이상이면 제어 과다 의심 |
| 2 | 히터 출력률 추이 | 운전이력 로그 | 설정온도 도달 전후 출력률 확인 | 설정온도 근처에서 출력률이 높게 유지되면 이상 |
| 3 | 안정화 시간 | EC 모니터 화면, 로그 | 안정화 시간이 표시되는지 확인 | 계속 미표시이면 안정화 실패 |
| 4 | 히터 구동 파형 | 로직분석기 | 필요 시 히터 구동 신호 파형 확인 | 출력률이 급격히 반복 변동하면 이상 |

#### 조치

```text
1. 운전 정지
2. 제어 파라미터를 보수적으로 조정
3. 재가동 후 목표 온도 도달 시간과 목표 온도 초과량 확인
4. 목표 온도 초과량이 1°C 이내로 줄어드는지 확인
5. 안정화 시간이 정상적으로 표시되는지 확인
```

> 동일 현상을 “PID 게인(특히 Kp)을 낮춰 오버슈트를 줄였다”처럼 제어 파라미터 관점에서 기술하면 펌웨어 튜닝 근거가 더 분명해진다.

### 8.5 원인 E — 히터 출력 차단 불량

#### 발생 메커니즘

ALARM 이후 제어기는 히터 출력률을 0%로 낮추지만, 전력 스위칭 소자 또는 배선 이상으로 실제 히터 전원이 차단되지 않는 경우이다. 발생 빈도는 낮지만 안전 영향도가 크므로, 조건이 보이면 즉시 전원을 차단하고 점검한다.

#### 점검 절차

| 단계 | 확인 항목 | 도구 | 방법 | 판정 |
|-----|----------|------|------|------|
| 1 | ALARM 후 히터 출력률 | EC 모니터 화면, 로그 | 출력률이 0%인지 확인 | 0%가 아니면 제어 이상 |
| 2 | 출력률 0% 이후 온도 추이 | 운전이력 로그 | ALARM 후 온도가 계속 상승하는지 확인 | 계속 상승하면 차단 불량 의심 |
| 3 | 히터 구동 신호 | 멀티미터, 로직분석기 | ALARM 상태에서 구동 신호가 OFF인지 확인 | OFF가 아니면 제어/배선 이상 |
| 4 | 히터 전력 스위칭 소자 | 멀티미터 | 구동 신호 OFF 상태에서 히터 단자 전압 확인 | 히터에 전압이 유지되면 스위칭 소자 이상 |

#### 조치

```text
1. 24V 전원 즉시 OFF
2. 히터 전력 스위칭 소자 및 배선 확인
3. 풀다운 저항, 게이트 저항, 커넥터 접촉 상태 확인
4. 전력 스위칭 모듈 교체
5. 전원 인가 전 도통 및 단락 여부 확인
6. 재가동 후 ALARM 상황에서 히터 출력 차단 여부 확인
```

## 9. 복구 절차

원인 조치가 끝나면 아래 순서로 복구한다.

```text
Step 1. 냉각 대기
- 팬 동작 상태에서 온도가 복구 조건 이하로 내려가는지 확인한다.

Step 2. 복구 조건 확인
- EC 화면에서 복구 조건 충족 표시를 확인한다.
- 복구 조건 미충족 상태에서는 RESET 명령을 반복하지 않는다.

Step 3. RESET
- RESET 명령으로 ALARM 상태를 해제한다.
- 정상 응답 후 상태가 IDLE로 돌아오는지 확인한다.

Step 4. 재가동
- START 명령으로 재가동한다.
- 온도 상승, 목표 도달, 안정화 여부를 확인한다.

Step 5. 재발 여부 확인
- 최소 10분 이상 알람 재발이 없는지 확인한다.
```

## 10. 재가동 검증 체크리스트

| 항목 | 확인 방법 | 합격 기준 |
|------|----------|----------|
| 운전 상태 정상 전환 | EC 모니터 화면 | IDLE → HEATING |
| 온도 상승 정상 | EC 모니터 화면 | 설정온도 방향으로 완만하게 상승 |
| 히터 출력률 정상 | 운전이력 로그 | 설정온도 근처에서 과도한 출력 지속 없음 |
| 목표 온도 초과량 | EC KPI | 1°C 이내 |
| 안정화 시간 | EC KPI | 안정화 시간 표시 |

| 알람 재발 없음 | EC Alarm | 10분 이상 NONE 유지 |
